Against Zune68 Beta 5

Zune68 Beta 5 (2026.11.22, as released) and OpenMUI (2026-11-25), the same test on the same machine (A1200, OS 3.1), measured in one session on 2026-11-25. Each bar is the library's time as a share of MUI 3.8's; shorter is faster.

3.1×faster bringing back an iconified program (336 against 1,037 ms)

672 KBMUI-Demo's first program on Zune68 against 423.5 KB on OpenMUI (each further program 268 against 187 KB); Zune68's 434 KB library has every class inside and its 39 add-on classes are separate files

On OS 3.2.1 (Zune68 reports MUI 5 on every OS) Zune68 is faster than MUI 5 in 23 of 26 operations (2026-11-25); cycle set, radio set and list insert of one row take 1.5 to 1.8 times MUI 5's time. OpenMUI is faster than MUI 5 in all 26, and Zune68 takes 1.02 to 4.70 times OpenMUI's time in 25 of them; menu open + close is level (20.0 ms, both ask for IDCMP_MENUVERIFY there).
