Against the original Zune68

The same test on the same machine (OS 3.1). OpenMUI is Zune68 after a diet and three speed rounds.

55×faster moving a slider (2.7 ms against 150 ms)
53×faster through a chain of notifications (5.7 against 301 ms)
4×faster adding one list entry (8.5 against 34 ms)
2.7×faster bringing back an iconified program (372 against 991 ms)
1.5×faster typing, relayout and register pages
3× sloweronly at starting an empty program (49 against 15 ms): Zune68 has every class inside one 429 KB library, OpenMUI loads rarely used ones from files
