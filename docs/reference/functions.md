## MUI_NewObjectA

```c
Object * MUI_NewObjectA(CONST_STRPTR classname, struct TagItem * tags)
```

Offset -30, registers a0,a1. Variable-argument form: `MUI_NewObject`.

**Function**

Create an instance of the named MUI class with the supplied attributes. The class is looked up through MUI_GetClass(), then instantiated through intuition.library/NewObjectA().

**Inputs**

- `classid` - NUL-terminated class identifier. Built-in class names are case-sensitive. Use the MUIC_* identifiers where available.

- `tags` - Attribute/value pairs terminated by TAG_DONE, or NULL for the class defaults. Attribute types and ownership are defined by the selected class.

**Result**

The new object, or NULL if the class lookup or construction fails.

**Notes**

MUI_NewObject() is the variadic tag-list wrapper.

Release an independently owned object with MUI_DisposeObject(). If ownership is transferred to a parent, follow that parent's disposal contract instead of disposing of the child twice. This function does not establish a separate MUI error code.

## MUI_RequestA

```c
LONG MUI_RequestA(APTR app, APTR win, LONGBITS flags, CONST_STRPTR title, CONST_STRPTR gadgets, CONST_STRPTR format, APTR params)
```

Offset -42, registers d0,d1,d2,a0,a1,a2,a3. Variable-argument form: `MUI_Request`.

**Function**

Display a requester and wait for a response. With a MUI application, create a temporary window and process the application's input until a requester return ID is received. With app == NULL, delegate to intuition.library/EasyRequestArgs() instead.

**Inputs**

- `app` - MUI Application object, or NULL for the Intuition fallback.

- `win` - MUI Window object used as the reference window, or NULL. Ignored by the Intuition fallback.

- `flags` - Ignored by this implementation; pass zero.

- `title` - Requester title. With a MUI application, NULL selects MUIA_Application_Title.

- `gadgets` - Non-NULL NUL-terminated button labels separated by |. Supply at least one label and no more than 32 labels. On the MUI path, a leading * selects the active button; if several labels have it, the last one takes precedence.

- `format` - Non-NULL RawDoFmt-compatible message format.

- `params` - RawDoFmt() argument array for format, in format order, with each argument sized as format specifies. Supply a valid array whenever arguments are used. This is not a tag list.

**Result**

On the MUI path, buttons except the last return their one-based position; the last returns 0. A single button returns 1. Allocation or window-opening failure also returns 0. On the fallback path, return the result of EasyRequestArgs() unchanged.

**Notes**

This is a synchronous GUI call. Application methods and input handlers may run before it returns; the application is not put to sleep. The temporary requester is removed and disposed of before returning. Keep input strings, formatting arguments, and referenced objects valid for the duration of the call. MUI_Request() supplies positional formatting arguments, not tags.

**Bugs**

The 32-button array has no bounds check. More labels can overwrite memory. A button-construction failure can leave a partial requester. Application return IDs are neither saved nor replayed. IDs from 1 through the number of constructed buttons plus 1 can terminate the requester even if they came from another application action; other return IDs are consumed without being returned to the caller.


**Function**

Allocate an ASL requester through asl.library/AllocAslRequest(). For a file or font requester whose tags are all supported by the MUI file or font panel, return a MUI-managed requester instead, which MUI_AslRequest() runs as a MUI panel. **Result**

The allocated requester, or NULL.

**Notes**

MUI_AllocAslRequestTags() is the variadic tag-list wrapper.

Run the requester with MUI_AslRequest() and release it with MUI_FreeAslRequest(). Refer to ASL for the lifetime of tag payloads and requester-specific result fields.

## MUI_MakeObjectA

```c
Object * MUI_MakeObjectA(LONG type, IPTR * params)
```

Offset -120, registers d0,a0. Variable-argument form: `MUI_MakeObject`.

**Function**

Construct a predefined MUI object from positional arguments. The type selects a class or an object tree and the attributes used to construct it. The parameter array is not a tag list.

**Inputs**

- `type` - One of the MUIO_* values listed below.

- `params` - Array of IPTR-sized values in the order listed for type. Cast pointer and integer arguments to IPTR. No terminator follows the positional arguments.

- **MUIO_Label**: label, flags Text label. flags select SingleFrame or DoubleFrame, LeftAligned or Centered, and FreeVert using the corresponding MUIO_Label_* bits. Right alignment is the default. The low byte selects the highlight character; zero uses an underscore marker in the label. SingleFrame takes precedence over DoubleFrame, and LeftAligned over Centered.

- **MUIO_Button**: label Text button with relative-verify input and cycle-chain entry. The character after the first underscore is its control key.

- **MUIO_Checkmark**: label Toggle image. The label supplies the control key; it is not displayed beside the image.

- **MUIO_Cycle**: label, entries

- **MUIO_Radio**: label, entries Cycle or radio gadget. entries is a NULL-terminated array of string pointers. The label supplies the control key.

- **MUIO_Slider**: label, minimum, maximum Slider with MUIA_Numeric_Min and MUIA_Numeric_Max set from the signed limits. The label supplies the control key.

- **MUIO_String**: label, maxlen Framed string gadget. maxlen becomes MUIA_String_MaxLen; the label supplies the control key, not initial contents.

- **MUIO_PopButton**: imagespec Relative-verify image button using MUIA_Image_Spec.

- **MUIO_HSpace**: width

- **MUIO_VSpace**: height Rectangle with fixed width or height, respectively. Zero makes a stretchable spacer; a negative value makes one with weight -value.

- **MUIO_HBar**: height

- **MUIO_VBar**: width Horizontal or vertical separator with the specified thickness.

- **MUIO_MenustripNM**: newmenu, flags Menustrip from an NM_END-terminated NewMenu array. NM_TITLE precedes its items; NM_SUB follows its parent NM_ITEM. Labels, shortcuts, user data, exclusion masks, and the supported disabled/check/toggle flags are passed to the menu objects. MUIO_MenustripNM_CommandKeyCheck enables the special label handling described under BUGS.

- **MUIO_Menuitem**: label, shortcut, flags, userdata Menu item. flags use CHECKIT, CHECKED, MENUTOGGLE, and NM_ITEMDISABLED. userdata becomes MUIA_UserData.

- **MUIO_BarTitle**: label Horizontal separator with MUIA_Rectangle_BarTitle set to label.

- **MUIO_NumericButton**: label, minimum, maximum, format Numericbutton with signed limits. A non-NULL format sets MUIA_Numeric_Format; NULL retains the class default.

- **MUIO_CoolButton**: label, image, flags Image-and-text button when compiled with HAVE_COOLIMAGES and an image is available. image is a CoolImage pointer, or an image ID when MUIO_CoolButton_CoolImageID is set. Falls back to MUIO_Button when the image facility or image is unavailable.

- **MUIO_ImageButton**: label, imagepath Image-and-text button when the path can be locked for reading; otherwise a text button. The image specification is formed in a 512-byte buffer containing the prefix 3: and the path.

**Result**

The constructed object, or NULL for an unsupported type or failed construction. A non-NULL menustrip can be incomplete if allocation of an individual menu or item failed.

**Notes**

Dispose of an independently owned result with MUI_DisposeObject(), or transfer ownership to an appropriate parent. The parameter array itself is not retained; pointed-to data follows the constructed class's ownership rules. In particular, menu titles and shortcuts and Numericbutton format strings are borrowed, not copied here. MUI_MakeObject() is the variadic positional-argument wrapper.

**Bugs**

MUIO_Menuitem_CopyStrings is declared but not implemented. With MUIO_MenustripNM_CommandKeyCheck, a label whose second byte is NUL is advanced by two bytes and that advanced pointer is used for both title and shortcut. This does not implement the apparent intent of separate shortcut and display strings. Long ImageButton paths are silently truncated in the image specification, although the original path was used for the lock.

## MUI_Layout

```c
BOOL MUI_Layout(Object * obj, LONG left, LONG top, LONG width, LONG height, ULONG flags)
```

Offset -126, registers a0,d0,d1,d2,d3,d4.

**Function**

Set a child object's geometry relative to its parent's inner origin and lay out the child. For a virtual-group parent, subtract the parent's horizontal and vertical scroll offsets first.

**Inputs**

- `obj` - Non-NULL Area-derived child with a valid parent and initialized layout data. This helper is used by group layout code.

- `left, top` - Position relative to the parent's inner origin before virtual-group scroll offsets are subtracted.

- `width, height` - Dimensions stored in the child's geometry.

- `flags` - Passed in MUIM_Layout to a custom group subclass and otherwise ignored; pass zero.

**Result**

FALSE if width or height lies outside the child's minimum and maximum dimensions; the geometry is stored, but the child is not laid out. Otherwise the result of the child's layout method.

**Notes**

This helper does not request a redraw. The layout owner must supply suitable geometry. NULL objects and parentless objects are not accepted.

## MUI_ObtainPen

```c
LONG MUI_ObtainPen(struct MUI_RenderInfo * mri, struct MUI_PenSpec * spec, ULONG flags)
```

Offset -156, registers a0,a1,d0.

**Function**

Resolve a MUI pen specification against the rendering context. MUI and system pens refer to existing pens. A colormap specification selects an existing entry; negative indices count from the end of the colormap. An RGB specification uses ObtainBestPenA(), falling back to FindColor() when allocation fails.

**Inputs**

- `mri` - Initialized rendering context with a colormap and the draw information required by the selected specification.

- `spec` - NUL-terminated pen specification in a MUI_PenSpec structure. Supported prefixes are m (MUI pen), p (colormap index), s (system pen), and r (three hexadecimal RGB components). RGB components are separated by commas or given as six hexadecimal digits RRGGBB; r may be omitted.

- `flags` - Ignored by this implementation; pass zero.

**Result**

A pen token, or -1 if mri, spec, or the colormap is NULL, parsing fails, or a checked pen index is out of range. Use MUIPEN(token) to obtain the drawing pen number. An allocated pen has all bits of the upper word set.

**Notes**

Pass the complete token, not its masked pen number, to MUI_ReleasePen() with the same rendering context when finished. Keep that context and its colormap alive until the pen is released.

**Bugs**

System-pen indices are not range-checked. Supply a valid index into the rendering context's DrawInfo pen array.

## MUI_BeginRefresh

```c
BOOL MUI_BeginRefresh(struct MUI_RenderInfo * mri, ULONG flags)
```

Offset -192, registers a0,d0.

**Function**

Begin a refresh pass for a damaged simple-refresh window. Set the rendering context's refresh flag, lock the screen's LayerInfo, and call intuition.library/BeginRefresh().

**Inputs**

- `mri` - Non-NULL initialized rendering context. A present window must have a valid window layer and screen.

- `flags` - Ignored by this implementation; pass zero.

**Result**

TRUE if a refresh pass was begun. FALSE if there is no window, the window is not simple-refresh, its layer does not need refreshing, or this rendering context is already in refresh mode.

**Notes**

Only after TRUE, complete the pass with MUI_EndRefresh() on the same context. The LayerInfo lock remains held between these calls. Do not close the window or change the context during that interval.
